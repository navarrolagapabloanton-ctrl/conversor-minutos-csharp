# Conversor de minutos a segundos

Primer ejercicio de fundamentos de programación realizado en C#.

## Descripción

Aplicación de consola que solicita una cantidad de minutos y muestra su
equivalencia en segundos.

## Funcionalidades

- Convierte minutos en segundos.
- Comprueba que la entrada sea un número entero.
- Rechaza cualquier cosa que no sea un número.
- Rechaza números negativos.
- Permite realizar varias conversiones sin reiniciar el programa.
- Permite finalizar el programa mediante una respuesta S/N.

## Conceptos practicados

- Variables.
- Entrada y salida por consola.
- `Console.ReadLine()`.
- `int.TryParse()` y parámetros `out`.
- Condicionales `if` y `else`.
- Bucles `while` y `do while`.
- Variables booleanas.
- Interpolación de cadenas.
- Control de versiones con Git.
